# Novera Travel — Занзибар + Танзания

Статический сайт-визитка тура, готов к публикации на GitHub Pages.

## Публикация (GitHub Pages)

1. Залейте содержимое этой папки (`index.html`, `photos/`, `.nojekyll`, `robots.txt`) в корень вашего репозитория (например, `janaomirwomanclub-code/novera_zanzibar`), в ветку `main`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<название-репозитория>/`
   Для этого репозитория: https://janaomirwomanclub-code.github.io/novera_zanzibar/

## Свой домен (опционально)

Settings → Pages → Custom domain → укажите домен (например, `zanzibar.novera.travel`) и настройте у регистратора CNAME-запись на `<ваш-логин>.github.io`.

## Диагностика на телефоне

Откройте сайт с `?debug` в конце ссылки (например, `.../?debug`) — внизу слева появится панель с информацией о поддержке браузером нужных CSS-функций и ошибках скрипта, если они есть.

## Структура

- `index.html` — вся страница (HTML/CSS/JS в одном файле)
- `photos/` — все фотографии тура (внешние файлы, подгружаются лениво)
